# Ajmer Gift Charm 🎁

A premier Fortune-500 grade B2C and B2B corporate gifting e-commerce platform crafted with Rajasthan heritage craftsmanship, 24K gold foil personalization studio, multi-address CSV dispatch, and real-time WhatsApp concierge integration.

---

## 🌟 Key Highlights

- **Bespoke Hero Experience**: High-fashion typography featuring Cormorant Garamond, Playfair Display, and Great Vibes calligraphy script with photorealistic luxury still-life visuals.
- **Interactive Occasion Concierge**: Quick occasion filters (Birthdays, Anniversaries, Weddings, Corporate, Return Gifts).
- **Curated Craft Collections**:
  - Personalized Laser-Engraved Drinkware & Keepsakes
  - Antique Brass Lattice Lanterns & Soy Wax Candles
  - Hypoallergenic Huggable Plush Bears
  - Quilted Luxury Handbags & Timepieces
  - Royal Festive Gourmet Hampers
  - Floral & Gold Foil Stationery Essentials
- **Live Personalization Studio**: Real-time laser etching and monogram proofing.
- **Corporate Bulk B2B Portal**: Multi-address CSV spreadsheet dispatch, RFQ quotations, and GST Tax Invoicing (HSN/SAC compliant).
- **Instant WhatsApp Concierge**: Authentic floating WhatsApp button with live greetings and quick-order prompts.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production
```bash
npm run build
```
